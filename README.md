# 🔐 Password Strength Analyzer

A Python-based cybersecurity tool that evaluates the strength of user-entered passwords based on **length, complexity, and common-password detection**.

## 🚀 Features

* Checks password length
* Checks uppercase and lowercase letters
* Checks numbers and special characters
* Detects common passwords
* Rates password strength
* Provides suggestions for stronger passwords

## 🛠️ Technologies

* Python
* Regular Expressions
* Git & GitHub

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code** or **Command Prompt**.
3. Run the following command:

```bash
python password_analyzer.py
```

4. Enter your password when prompted.
5. The program will display the password strength and suggestions.
